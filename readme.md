# 🧮 Simple Calculator Using JavaScript

A simple and interactive calculator built using HTML, CSS, and JavaScript. This project performs basic arithmetic operations and demonstrates the use of DOM manipulation, event handling, and JavaScript logic to create a functional calculator application.

## 📖 Project Overview

This project allows users to perform basic mathematical calculations through an intuitive user interface. It is designed as a beginner-friendly JavaScript project to strengthen core frontend development skills.

## ✨ Features

- Addition, Subtraction, Multiplication, and Division
- User-friendly calculator interface
- Real-time display updates
- Button-based input system
- Clear and delete functionality
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```text
SIMPLE-CALCULATOR-USING-JAVASCRIPT/
│
├── index.html
├── style.css
└── script.js
```

## ⚙️ How It Works

1. Users enter numbers using the calculator buttons.
2. Mathematical operators can be selected for calculations.
3. JavaScript processes the input and performs the selected operation.
4. The result is displayed instantly on the calculator screen.
5. Users can clear the display and start a new calculation.

## 🧠 Concepts Practiced

- DOM Manipulation
- Event Handling
- JavaScript Functions
- Arithmetic Operations
- Conditional Statements
- User Interface Interaction

1. Clone the repository:
